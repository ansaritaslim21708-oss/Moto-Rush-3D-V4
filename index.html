HOW TO PLAY

⌨️ Keyboard

W / ↑ Accelerate
S / ↓ Brake
A,D / ←,→ Steer
SPACE Nitro
P Pause

📱 Touch

Use the on-screen buttons to steer, brake, accelerate and activate Nitro.

🪙 Collect

Coins increase your score. The magnet attracts nearby coins.

🛡️ Survive

Shield blocks collisions. Avoid barriers, cars and rocks.

ABOUT THE PROJECT

Moto Rush 3D is a browser-based 3D motorcycle racing game created as a first-year academic project.

HTML5CSS3JavaScriptThree.jsGitGitHub Pages

Concepts demonstrated: 3D rendering, game loop, keyboard/touch input, collision detection, scoring, levels, power-ups, local storage and responsive UI.
